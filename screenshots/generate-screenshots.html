ShiftPlanner PWA Screenshot Generator

Generates the two manifest screenshots that enable the richer PWA install UI. Click each Download button and save the file into this screenshots/ folder with the exact filename shown (the manifest references these exact names + sizes).

Files to produce (save into screenshots/):
  • screenshot-wide.png — 1280×720, form_factor: "wide" (desktop install UI)
  • screenshot-narrow.png — 720×1280, narrow (mobile install UI)
