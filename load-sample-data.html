SAMPLE DATA LOADER — for testing only. Writes synthetic data into your local ShiftPlanner storage.

ShiftPlanner Sample Data

This page seeds a synthetic staff list (10 nurses + 10 housekeeping, plus a covering G-shift person on each tab) straight into ShiftPlanner's localStorage. After loading, open ShiftPlanner.html, then click Generate on each tab to build the rotas.

What this writes

Load sets exactly these keys; Clear removes them (staff + org name only — it does not touch any rotas you've generated, theme, or edits):

  • sp_staff — the full staff list (nurses, housekeeping, incompatible pairs)
  • sp_orgName — the sample organisation name

It deliberately does not touch sp_rota_*, sp_edits_*, or sp_theme. Generated rotas are left to the app.
