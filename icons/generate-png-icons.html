ShiftPlanner PNG Icon Generator

Generates PNG app icons that match the existing SVG design. Chrome needs PNG icons to show the "Install app" banner. Click each Download button and save the file into this icons/ folder with the exact filename shown.

Files to produce (save into icons/):
  • icon-192.png — 192×192, standard
  • icon-512.png — 512×512, standard
  • icon-maskable-512.png — 512×512, maskable (full-bleed background, safe-zone padding)
