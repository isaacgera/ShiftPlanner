ShiftPlanner User Guide

A shift rota generator for healthcare institutions. Generates fair, balanced monthly schedules for Nurses and HouseKeeping staff.

1. Getting Started

First Time Setup

  1. Open ShiftPlanner.html in your browser (Chrome, Edge, or Firefox recommended).
  2. You'll see "No staff configured" — click Staff Setup to add your team.
  3. Add each staff member with their name and role:
    • Nurse — regular shift-working nurse
    • HouseKeeping — housekeeping staff
    • G-Shift — the person on fixed General shift (10AM–6PM daily, off Sundays)
  4. Set your organisation name by clicking the text under "ShiftPlanner" in the header.
  5. Click Generate to create your first rota.
Your staff data is saved in the browser's localStorage. It persists across sessions but will be lost if you clear browser cache. Use Export JSON in Staff Setup to back up your data.

Installing as an App (PWA)

When hosted on a web server (e.g., GitHub Pages), you can install ShiftPlanner as an app:

  • Desktop (Chrome/Edge): Click the install icon in the address bar, or Menu → "Install ShiftPlanner"
  • Mobile (Android): Tap Menu → "Add to Home Screen"
  • Mobile (iPhone): Tap Share → "Add to Home Screen"

Once installed, it works fully offline — no internet needed.

4. Generating a Rota

Nurses Tab

For 7 nurses + 1 G-shift person:

  • Each nurse gets ~9M + 9A + 9N + 4O per 31-day month (or 8-9 of each for 30-day months)
  • Night shifts are in blocks of 4-5 consecutive days (never broken by offs)
  • Offs are spaced ~5-8 days apart, never during Night blocks
  • Maximum 1 nurse off per day
  • MA is used only when mathematically necessary (0-2 per nurse)
  • Incompatible pairs are never on the same M/A shift together

HouseKeeping Tab

For 3 housekeeping staff + 1 G-shift person:

  • 3 phases of ~10-11 days: each staff rotates through M → A → N
  • 4 offs per staff, only from M/A days (never during Night phase)
  • When someone is off, the M-person (or A-person) covers MA (Morning + Afternoon)
  • MA balanced to ~4 each across staff
  • Monthly rotation ensures different starting positions each month
  • Expected per 31-day month: ~10-11 N, ~7 M, ~7 A, ~4 MA, 4 O

Night Shift Preference

In Staff Setup, each nurse/HK staff can set preferred weeks for Night shift:

  • Nurses: W1 (days 1-7), W2 (days 8-14), W3 (days 15-21), W4 (days 22-31)
  • HouseKeeping: P1 (phase 1), P2 (phase 2), P3 (phase 3)

The algorithm honours preferences as a best-effort — it places preferred nurses in their chosen weeks when possible without disrupting fairness.

5. Editing the Rota

Click-to-Edit

  1. Click any shift cell in the rota table.
  2. A popup appears with all shift options (M, G, A, N, O, PL, MA, AN).
  3. Select the new shift — it's applied immediately.
  4. If the change violates a rule (coverage, incompatible pair), a warning appears. You can "Apply Anyway" or cancel.

Save, Undo, Re-generate

  • Save: Appears after manual edits. Confirms your changes are stored.
  • Undo: Reverts the last manual change (up to 20 levels).
  • Re-generate: Creates a new rota but preserves all your manual edits. Useful if you want the algorithm to fix the remaining cells around your locked changes.

Add Off on Fully-Staffed Days

Days with full coverage show a green * in the date header. Click it to assign an off to an eligible nurse.

6. Staff Setup

Managing Staff

  • Add: Type a name and click Add. They're added with the default role for the current tab.
  • Rename: Click the name or the ✏️ icon. Updates the rota data automatically.
  • Role: Change via the dropdown (Nurse / HouseKeeping / G-Shift).
  • Active/Inactive: Uncheck to exclude from rota generation without deleting.
  • Remove: Click the × button to delete permanently.

Incompatible Pairs

Select two nurses who should never be on the same M or A shift together. They can still be on Night together (blocks are pre-planned).

Backup / Restore

  • Export JSON: Downloads all staff data (names, roles, preferences, incompatible pairs, org name) as a JSON file.
  • Export CSV: Same data in spreadsheet-friendly format.
  • Import: Upload a previously exported JSON or CSV file to restore staff data after a cache clear or on a new device.
Important: After clearing browser cache, your staff and rota data will be lost. Always keep an exported backup file. Use Import to restore.

8. Export PDF / Print

  1. Click Export PDF (bottom-right of header).
  2. The browser's print dialog opens with:
    • Filename: ShiftPlanner Nurses August 2026 (auto-generated)
    • Layout: A4 Landscape
    • Content: Header + active tab label + legend + rota table + shift count — all within a border
  3. Select "Save as PDF" or print directly.
The PDF is designed to fit on a single A4 landscape page. Share it via WhatsApp or print for wall display.

9. Monthly Workflow

Recommended monthly process:

  1. Select the upcoming month from the month picker.
  2. Click Generate to create the rota.
  3. Review the rota visually — check N-blocks, offs spacing, coverage.
  4. Make manual adjustments if needed (click cells to edit).
  5. Click Export PDF to save/print.
  6. Share the PDF via WhatsApp or pin it on the noticeboard.
  7. Repeat for HouseKeeping tab.

10. Tips and Notes

  • Generate rotas up to 5 months in advance using the month picker.
  • The algorithm rotates positions each month — no nurse always gets the same pattern.
  • PL (Planned Leave) is manual-only. Click a cell and select PL. It's preserved on Re-generate.
  • The app works entirely in the browser — no data is sent to any server.
  • All data is stored locally in your browser's localStorage.
  • For best results, use Chrome or Edge on desktop for generation, then share the PDF.
